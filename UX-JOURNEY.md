## Navigation contract

- Header: 5 links + CTA, one line, active-page underline. Never more.
- Chapter rail: orientation only, never required; hidden on touch/reduced-motion.
- Footer: lockup + 3 columns + legal strip. No sitemap bloat.
- All anchors smooth-scroll with 128px offset (sticky header clearance).

## Transition language

- Page loads: static first paint (SEO + speed), intro overlay only on first visit.
- Between beats: hard cuts (borders), not fades — editorial rhythm.
- Hover: 200–250ms lifts, shine sweeps, sliding arrows. Nothing longer.
- Ambient: float, spin, marquee, pulse — transform/opacity only.

next step or the contact.
